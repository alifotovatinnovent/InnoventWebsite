// Architecture · How it works

Five layers. One continuous loop.

Every agent on Innfini runs through the same five-layer runtime. Model-agnostic at the top. Sensor-aware at the bottom. Auditable end to end.

L5 Reasoning Plan · decide · explain
Multi-model planner. Claude · GPT-4o · Llama 3 · on-prem — routed per task, per cost target, per data-residency rule. Chain-of-thought with structured tool-use, retry on failure, fallback on timeout.

L4 Tools Connectors · APIs · actions
50+ first-class connectors. ERP (SAP, Oracle, NetSuite), WMS (Manhattan, Blue Yonder), MES, SCADA, Slack, Teams, JIRA, ServiceNow, Maps, CCTV, RFID, BLE. Custom tools via OpenAPI in <30 minutes.

L3 Memory Graph · vectors · temporal

Every action is gated. RBAC scopes, action approvals, kill-switches, monetary & rate caps. SOC 2 Type II + GDPR + HIPAA audit trail. Nothing leaves the runtime without a policy match.

// Agent Builder · No-code workflow

Build your own agent. In an afternoon.

A visual builder for ops teams — no Python, no MLOps. Describe the goal, pick the tools, set the guardrails. The runtime handles planning, retries, fallbacks, logging and rollout.

  1. 01
    Define the goal

    Plain English. "Keep dock-door dwell under 22 minutes." The builder turns it into a measurable objective with success criteria.

  2. 02
    Connect tools & signals

    Pick from 50+ connectors and any sensor source already on Innfini. Agent gets typed inputs and tool schemas auto-generated.

  3. 03
    Set the guardrails

    RBAC, approval thresholds, monetary caps, rate limits, escalation paths. Test in shadow-mode against last 30 days of live data.

  4. 04
    Deploy & observe

    Promote to production with one click. Every decision streams to the ledger. Roll back, A/B test, or fork at any time.
