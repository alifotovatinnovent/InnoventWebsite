// How Hybrid Edge works

Control above. Action below.

Innfini Cloud governs identity, rules, policy, AI training and dashboards. Edge nodes execute at every site — sub-10ms inference, local rules, offline-safe buffering.

  1. 01 · Cloud

    Control Plane

    Identity, policy, rule authoring, AI training, dashboards and audit live in Innfini Cloud.

  2. 02 · Edge

    Site Nodes

    x86 / ARM edge runtime at every site — runs rules, AI inference and connects local devices.

  3. 03 · Sync

    Bi-Directional

    mTLS gRPC tunnel for rules-down + events-up. Backpressured, dedup-safe.

  4. 04 · Degraded

    Operate Offline

    Network drop? Edge keeps capturing, deciding, alerting and buffering — no data loss.

  5. 05 · Catch-up

    Auto-Resync

    On reconnect, edge replays its ledger to cloud — chronologically, with provenance preserved.

  6. 06 · Update

    Rolling Deploy

    Cloud-driven rolling rule and model updates — staged by site, ring-tested before fan-out.
