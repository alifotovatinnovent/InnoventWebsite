// How the graph works

From isolated records to connected intelligence.

Five layers. Every operational element becomes a typed node, every action becomes an event, every relationship becomes context — and the platform's AI gets the data it needs to reason properly.

  1. 01 · Objects

    Typed Nodes

    Every asset, person, place, device, workflow and system record becomes a typed node with attributes, status, ownership and lifecycle.

  2. 02 · Relationships

    Connected Edges

    Nodes are linked through ownership, location, assignment, detection, approval and dependency relationships — built continuously, automatically.

  3. 03 · Events

    Time-stamped Timeline

    Every movement, reading, alert, update, inspection and workflow step becomes a time-stamped event linked to the objects it touched.

  4. 04 · Context

    Auto-built Context

    Live events fuse with object history, rules, ownership, location and operational status — so every signal arrives with its full backstory.

  5. 05 · Intelligence

    AI & Decisioning

    Agents, ML models and the Decision Engine query the graph — and reason with full context, not isolated records.

// Relationship schema

Every permitted edge, enforced at write time.

The graph is not free-form. Source type, target type and cardinality are declared up front, so a malformed relationship cannot be created — and a traversal can be reasoned about before it runs.

object-event-graph · edges
// Temporal model

The graph remembers every version.

Two clocks, not one: when a fact was true, and when the system learned it. Late data lands at its real time without rewriting history.

object-event-graph · temporal
// Query performance

Traversal speed is the product.

A two-hop query is a join. A five-hop query is an answer. Indicative figures at production scale.

// Governance

Authority is evaluated hop by hop.

A shared graph does not mean shared access. Every node and every edge in a traversal is authorised individually — allowed, redacted or denied — and the whole decision trail is written to audit, including what was refused.
